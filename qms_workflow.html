Step 0 — Product Selection

Our Real-World Example Products

We chose Metformin HCl — one of the world's most prescribed diabetes medications — because its manufacturing process is well-documented, regulated, and touches nearly every QMS module from raw material intake to post-market surveillance.

Active Pharmaceutical Ingredient (API)

Metformin Hydrochloride

A biguanide compound synthesized via chemical reaction of dimethylamine and 2-cyanoguanidine. Used globally as a first-line treatment for Type 2 Diabetes Mellitus. Manufactured under strict GMP conditions with multiple in-process controls.

CAS: 1115-70-4 MW: 165.62 g/mol Synthesis: Chemical ICH Q7 (API GMP) USP Monograph
Finished Dosage Form (FDF)

Metformin HCl 500mg ER Tablets

Extended-release oral tablet formulated with Hydroxypropyl Methylcellulose (HPMC) matrix. Provides controlled drug release over 8–12 hours. Branded equivalent to Glucophage XR. Each batch = 500,000 tablets. Packaged in 60-count HDPE bottles.

Dose: 500mg Release: Extended (ER) Route: Oral ICH Q8/Q9/Q10 21 CFR 314

Phase-by-Phase QMS Workflow

Each manufacturing phase triggers specific QMS modules. Below is the complete workflow showing what happens, when, and which QMS module is activated.

🧾
Phase 1
Raw Material Receipt & Quality Control
Incoming QC

Before any manufacturing begins, all incoming raw materials — including Dimethylamine, 2-Cyanoguanidine (for API) and HPMC, Magnesium Stearate (for FDF) — must pass incoming quality control. The warehouse is on quarantine hold until QC approves.

📋
CoA Review
Certificate of Analysis from supplier verified against approved specifications for identity, purity, assay.
Document Control
🔬
Identity Testing (IR/HPLC)
Infrared spectroscopy confirms material identity. HPLC checks purity ≥99.5% for Dimethylamine.
QC Lab
⚠️
Out-of-Spec (OOS) Alert
If moisture content of HPMC exceeds 5% — OOS triggered. Material rejected. Deviation opened automatically.
Deviation
✅
Material Approval
QC Analyst approves via electronic signature. System releases quarantine. Material status → "Approved".

Phase 2
API Manufacturing — Metformin HCl Synthesis
GMP Production

Metformin HCl is synthesized via condensation reaction of Dimethylamine + 2-Cyanoguanidine under controlled temperature (130–150°C) and pressure. The process has 4 critical control points monitored by in-process QC.

📄
Batch Manufacturing Record
Electronic BMR issued from template. Each step requires operator sign-off + timestamp per 21 CFR 211.188.
Document Control
🌡️
In-Process Controls (IPC)
Reaction pH monitored every 30 min. Yield check at intermediate stage. Particle size post-milling: 10–50μm.
QC / IPC
🚨
Equipment Alarm — Reactor
Temperature spike to 165°C (limit: 155°C). Equipment deviation raised. Production paused. Investigation begins.
Deviation
👨‍🔬
API Characterization
Final API tested: Assay, Heavy Metals, Residual Solvents (ICH Q3C), Microbial Limits. All vs. USP spec.
QC Lab
⬇️
🚨
QMS Module Triggered
Deviation Management — Reactor Temperature Excursion
Critical Deviation

Real Scenario: During Batch MFM-2024-0047, Reactor R-03 temperature reached 165°C (limit: 155°C) for 12 minutes. Automatic deviation triggered in QMS.

📝
1. Deviation Report Opened
Operator logs event within 30 min. Classification: Critical (potential impact on product quality). Batch placed on hold.
Deviation Module
🔍
2. Root Cause Investigation
5-Whys & Fishbone analysis. Root cause: Faulty thermocouple sensor. Secondary: Calibration schedule missed.
Deviation Module
🧪
3. Impact Assessment
API assay tested: 99.7% (pass). Impurity profile unchanged. QA concludes: Batch MFM-2024-0047 acceptable with justification.
QC + QA Review
📊
4. CAPA Initiated
Deviation escalated to CAPA because root cause is systemic (calibration schedule). Corrective action required within 30 days.
CAPA Triggered
⬇️
🔧
QMS Module Triggered
CAPA — Corrective & Preventive Action
Systemic Fix

Since the thermocouple calibration miss is systemic (could affect all reactors), a formal CAPA is raised to fix the root cause and prevent recurrence across all production equipment.

🛠️
Corrective Action
Replace thermocouple on Reactor R-03. Emergency calibration of all 6 reactors. Calibration certificates updated in QMS.
CAPA
🔒
Preventive Action
Calibration frequency changed from 6-monthly to quarterly. Automated QMS reminder set. Checklist updated in SOP-MAINT-042.
CAPA + Change Control
🎓
Training Requirement
All maintenance technicians re-trained on calibration SOP. Training records captured in QMS. Competency assessment completed.
Training Module
✔️
CAPA Effectiveness Check
After 90 days: zero calibration overruns detected across all reactors. CAPA marked "Effective" and closed.
CAPA Closure
⬇️
💊
Phase 3
FDF Manufacturing — Metformin 500mg ER Tablets
Tablet Production

Approved Metformin HCl API is transferred to the FDF facility. The tableting process involves granulation → drying → blending → compression → coating → packaging. Each step requires IPC and operator verification.

🌀
Wet Granulation
API + HPMC granulated with purified water. IPC: LOD moisture 1.5–2.5%. Granule size distribution checked.
IPC Monitoring
⚡
Compression
Tablet press set to 500mg ± 2% weight. IPC every 15 min: hardness 8–12 kP, friability <1%, thickness 4.5mm.
IPC / QC
🎨
Film Coating
Opadry white coating applied. IPC: weight gain 2–3%. Visual inspection: no defects, uniform color, no twin tablets.
Visual QC
📦
Packaging & Labelling
HDPE 60-count bottles. Label reconciliation 99.9%. Batch number / expiry date verified. Line clearance documented.
BMR + Reconciliation
⬇️
✅
Phase 4
Quality Review & Batch Release
Final QA Gate

The Qualified Person (QP) performs final Batch Record Review. All deviations, OOS events, and CAPA actions are reviewed. Only after complete review does the QP provide electronic batch certification for market release.

📑
Batch Record Review
QA reviews 100% of BMR entries. Verifies: all IPCs passed, all deviations closed or justified, no open CAPAs.
Batch Record
🧫
Finished Product QC
Dissolution (Q=80% at 8h), Assay (98–102%), Content Uniformity (AV≤15), Microbial (<100 CFU/g) — all per USP.
Final Release Testing
🔏
QP Certification
Qualified Person signs batch electronically. 21 CFR Part 11 audit trail generated. Batch status → "Released".
21 CFR Part 11
📊
Stability Sample Retained
Retention samples stored at 25°C/60%RH and 40°C/75%RH per ICH Q1A. QMS schedules stability pulls at 3, 6, 9, 12, 24 months.
Stability Module

Phase 5
Post-Market Surveillance & Recall Management
Market Safety

After distribution, the QMS continues to monitor product quality through complaint handling, stability results, and regulatory signals. Scenario: 6 months post-release, a complaint arrives about tablets sticking together in the bottle (twin tablets).

📞
Customer Complaint Logged
Pharmacist reports fused tablets from Batch MFM-FDF-2024-0047. Complaint recorded. QMS assigns Complaint #C-2024-0312.
Complaint Module
🔍
Investigation Opened
Retained sample inspected: 0.12% twin tablets found (limit: 0%). IPC coating log reviewed — brief humidity excursion noted.
Deviation Investigation
🚨
Recall Decision
Risk assessment: Class III recall (unlikely to cause adverse health consequences but violates GMP). FDA notified within 3 days per 21 CFR 7.
Recall Management
🔁
CAPA & Process Improvement
Coating room humidity control upgraded. SOP updated. New IPC limit added: humidity <45%RH during coating. Re-validation performed.
CAPA + Change Control

QMS Module Reference

Key QMS Modules Used in This Workflow

Each module in a QMS like AIVOA handles a specific quality event. Here's what each one does in the pharma context.

🚨
Deviation Management
Triggered: Any unplanned event departing from SOP/spec
  • →Event detected & reported within 24h
  • →Classification: Minor / Major / Critical
  • →Impact assessment on batch/product
  • →Root cause investigation (5-Whys, Fishbone)
  • →Disposition: Accept / Reject / Rework
  • →Escalate to CAPA if systemic
🔧
CAPA
Triggered: Systemic issues, audit findings, recurring deviations
  • →CAPA initiation with due date
  • →Corrective action (fix the immediate problem)
  • →Preventive action (stop recurrence)
  • →Implementation with evidence
  • →Effectiveness check after 60–90 days
  • →CAPA closure with QA sign-off
🔬
QC Lab Management
Triggered: Every incoming RM, in-process, and finished product test
  • →Sample receipt and logging
  • →Test assignment to analyst
  • →Results entry with audit trail
  • →OOS/OOT investigation workflow
  • →Second analyst verification
  • →QA approval for release
📋
Document Control
Triggered: Any SOP creation, update, or BMR issuance
  • →Document creation with version control
  • →Review & approval workflow
  • →Periodic review scheduling
  • →Obsolete document archival
  • →BMR issuance from master template
  • →21 CFR Part 11 electronic signatures
📣
Recall Management
Triggered: Safety signals, market complaints, regulatory alerts
  • →Recall classification (Class I/II/III)
  • →Distribution traceability lookup
  • →Customer/distributor notifications
  • →FDA notification within 3 days
  • →Recall effectiveness check
  • →CAPA linkage & closure
🎓
Training Management
Triggered: New hires, SOP updates, CAPA actions, audit findings
  • →Training plan per role/function
  • →SOP-linked training assignments
  • →Completion tracking with due dates
  • →Competency assessment & scoring
  • →Training record with e-signature
  • →Overdue training alerts
